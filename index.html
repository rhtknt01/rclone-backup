rclone backup

This is a private, personal tool. Its owner uses it to copy files from their own computer to their own Google Drive, as a backup.

It is built on rclone, a free and open-source program for copying files to cloud storage.

What it does with Google Drive

  • It uploads backup copies of the owner's files to the owner's Google Drive.
  • It can only see and change the files it uploaded itself. It cannot see the rest of the Drive.
  • It is not offered to the public, and nobody else can sign in to it.
